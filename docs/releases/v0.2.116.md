# Harness v0.2.116

Stable desktop patch release for macOS, Windows and Linux.

## Split panes stop shaking

- With many chats split side by side, a narrow pane's composer could switch
  between its one-line and full-height layouts on every frame, so the pane
  shook continuously. The model name had squeezed the text box to almost
  nothing, and the composer misread that measurement. It now settles on the
  full-height layout and keeps it until the pane is wide enough again.
- A narrow composer no longer shows a one-line bar with no room to type.
