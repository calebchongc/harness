# Harness v0.2.118

Stable desktop patch release for macOS, Windows and Linux.

## graff tui keeps itself current

- `graff tui` now updates itself when you start it. At most every six hours
  it checks the newest Harness release; if there is a newer terminal client,
  it downloads it, checks it against the release's checksum, switches to it
  and starts it. If anything goes wrong, you get the version you had, and it
  tries again next time. Set `HARNESS_TUI_AUTO_UPDATE=0` to turn it off.
- The app no longer replaces a newer terminal client with its own older one.
- A Harness update installs its terminal client even when the release's
  terminal files finish uploading after the app: it retries every ten
  minutes for up to two hours instead of waiting for the next launch.

## Text size from the keyboard

- ⌘= (or ⌘+) makes text bigger, ⌘− smaller, and ⌘0 returns to the default,
  like zoom in a browser; Ctrl on Windows and Linux. The keys step through the
  sizes in Settings → Appearance and work while you type in the composer
  without adding anything to your message. They are also under View.

## Signing in keeps your projects whole

- Importing your local work after signing in could add a second copy of a
  project when both your local and your account workspace already had the
  same folder on this computer, splitting its chats between the two. The
  import now adds those chats to the project you already have.

## Staying signed in through a dropped connection

- A sign-in refresh that was cut off by a dropped connection could sign you
  out the next time Harness opened, making your chats look gone. The
  Codegraff account service now accepts that retried refresh, so you stay
  signed in. (This was a server fix; it applies to every Harness version.)
