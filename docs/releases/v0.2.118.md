# Harness v0.2.118

Stable desktop patch release for macOS, Windows and Linux.

## graff tui keeps itself current

- `graff tui` now updates itself when you start it. At most every six hours
  it checks the newest Harness release; if there is a newer terminal client,
  it downloads it, checks it against the release's checksum, switches to it
  and starts it. If anything goes wrong, you get the version you had, and it
  tries again next time. Set `HARNESS_TUI_AUTO_UPDATE=0` to turn it off.
- The app no longer replaces a newer terminal client with its own older one.
- A Harness update installs its terminal client even when the release's
  terminal files finish uploading after the app: it retries every ten
  minutes for up to two hours instead of waiting for the next launch.
