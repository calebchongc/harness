# Harness v0.2.122

## Stopping a Claude turn keeps its background work running

Stopping a Claude Code turn, or sending a message with "send now" while one
was running, used to shut down the whole `claude` process. Every background
task in the session went with it: background subagents, monitors and
background shell commands. The next turn started a new process, and the CLI
later reported those tasks as stopped because the previous session ended.

Claude Code's own interrupt ends only the current turn, and Harness now uses
it that way. Stop ends the turn, the process keeps running, and its background
tasks finish and report back as they would have without the interrupt. The
next message goes to the same process. If the CLI doesn't end the turn within
a few seconds, Harness still stops the process as before.

A message with images no longer restarts the process either. It is delivered
to the running Claude session like any other message, and the images go with
it. Changing the model still starts a new process, which resumes the same
conversation.

## The model picker shows the right keys on Windows and Linux

The rows of the model picker are numbered so you can pick one from the
keyboard. They always read ⌘1 to ⌘9, which on Windows and Linux means the
Windows (Super) key, while the keys that work there are Ctrl+1 to Ctrl+9.

The rows now show Ctrl+1 to Ctrl+9 on Windows and Linux, and ⌘1 to ⌘9 on
macOS as before. Those keys pick the model even if you have changed the
jump-to-session shortcuts that normally share them.

## Other keyboard and layout fixes

- **Session shortcuts keep your tabs.** Cmd+1–9 (Ctrl+1–9 on Windows and
  Linux) and Ctrl+Tab cycling now open the session the same way a sidebar
  click does: they focus its existing tab or give it a new one, instead of
  replacing the conversation in the current tab.
- **Close a tab without archiving.** Cmd+Option+W on macOS, or Ctrl+Alt+W on
  Windows and Linux, closes the tab or pane without archiving its session,
  even when archive-on-close is on. Rebind it in Settings → Shortcuts →
  Sessions.
- **Shift+Backspace and Shift+Delete work in the composer.** They used to do
  nothing while Shift was held.
- **Footer icons no longer overlap in narrow panes.** Branch, checkout, pull
  request and usage controls keep their spacing in narrow split panes.
