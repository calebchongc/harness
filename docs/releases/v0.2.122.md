# Harness v0.2.122

## The model picker shows the right keys on Windows and Linux

The rows of the model picker are numbered so you can pick one from the
keyboard. They always read ⌘1 to ⌘9, which on Windows and Linux means the
Windows (Super) key, while the keys that work there are Ctrl+1 to Ctrl+9.

The rows now show Ctrl+1 to Ctrl+9 on Windows and Linux, and ⌘1 to ⌘9 on
macOS as before. Those keys pick the model even if you have changed the
jump-to-session shortcuts that normally share them.
