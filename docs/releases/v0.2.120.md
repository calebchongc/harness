# Harness v0.2.120

## New worktrees set themselves up from `.agents/`

A chat that starts in a new worktree used to get a bare checkout: no `.env`,
no installed dependencies, nothing the project's own setup prepares. Harness
now reads the tool-neutral `.agents/` files right after it creates the
worktree, before the chat's agent starts:

- **`.agents/linked`** lists paths, one per line. Each one that is gitignored
  in your main checkout, exists there, and is missing from the new worktree
  becomes a symlink to the main checkout's copy, so a `.env` edited once is
  current in every worktree. Tracked files, `..`, globs and missing paths are
  skipped, and nothing is moved or deleted. (macOS and Linux.)
- **`.agents/prepare`** runs from the new worktree. Keep it fast and safe to
  repeat; Harness waits up to 90 seconds for it, then lets a longer one finish
  in the background while the chat starts.

```
# .agents/linked
/.env
secrets/
```

```sh
#!/bin/sh
# .agents/prepare
set -eu
pnpm install --frozen-lockfile
```

graff 0.302.36 does the same for the worktrees it creates.
