# Harness v0.2.121

## Codex asks you to sign in instead of failing with a 401

Codex has its own ChatGPT sign-in, separate from graff's. On a computer where
Codex had never signed in, such as a new Linux server, a chat with Codex
showed five "Reconnecting... n/5" errors and then
`401 Unauthorized: Missing bearer or basic authentication`, even when graff's
ChatGPT sign-in on the same computer read "Signed in".

Codex reports that failure with a typed 401, and Harness now answers it with
the ChatGPT sign-in card. The card signs Codex in on the computer running the
chat with a device code, so it works the same for a remote server as for this
Mac, and Resume continues the chat afterwards. The retry errors no longer
appear. A 401 from a custom provider in Codex's `config.toml` is still shown
as an error, because signing in to Codex can't fix that provider's key.
