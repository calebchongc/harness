# Harness v0.2.124

Stable desktop patch release for macOS, Windows and Linux.

## Graff sign-in naming

- Settings → Accounts names graff's own ChatGPT sign-in plainly **ChatGPT**,
  and the separate Codex login **ChatGPT (old Codex)**. The row most people
  want was the one carrying a qualifier ("ChatGPT (new)") while both read as
  ChatGPT, so the choice between them was unclear. The sign-in dialog now says
  "Sign in to ChatGPT".
- Labels only: the same `chatgpt-new` credential and flow, with no change to
  the agent, account or model a conversation uses.

## Error chips

- Error chips on iOS and Android restack like the desktop one: the warning
  glyph and label stay on the header line and the message wraps below them,
  growing to fit instead of truncating after one line. The message stays
  selectable.

## Model picker

- The picker's agent tabs are labelled and scroll, so a machine with many
  harnesses no longer crowds the top of the model list.
- Ctrl+Tab and Ctrl+Shift+Tab cycle agents inside the picker without taking
  Tab away from the search field. This is the picker's agent row; the sidebar's
  Ctrl+Tab for open sessions is unchanged.

## CLI detection

- A CLI whose `--version` probe is slow — the first run after an update, while
  macOS scans it — no longer loses its PATH precedence to an older install on
  the same machine, and that timeout is no longer cached like a failure.

## Linux

- Arch Linux packages (`.pkg.tar.zst`) are published for x86_64 and aarch64
  alongside the tarballs, and the x86_64 package is installed with `pacman -U`
  on a real Arch container before a release ships.
- Pacman installs are not self-updated: reinstalling the package is the update
  path, and the in-app updater reports the install as unmanaged rather than
  rewriting `/usr/bin` under the package manager.

Mobile app and terminal-client packages are distributed separately from this
desktop release.
