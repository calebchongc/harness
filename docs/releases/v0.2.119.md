# Harness v0.2.119

Stable desktop patch release for macOS, Windows and Linux.

## Windows keeps itself up to date

- Harness on Windows now checks for new releases and installs them, like the
  Mac and Linux apps. It also keeps its own copy of graff current, replacing a
  running `graff.exe` safely.

## No more "Working" forever

- A turn the agent started on its own, which left a tool row open, could keep
  the chat on "Working" indefinitely. It now settles once the agent goes quiet,
  and the leftover tool row is closed.

## Sending while the agent answers

- Sending a message with an image, or after switching model, effort or
  sandbox, while the agent was still answering used to stop that answer and
  restart the agent, ending it as "interrupted by user". The message now waits
  in the queue and goes out when the answer is done.
- Every stop is logged with its reason (Stop, send now, settings change,
  dismissed question, deleted project, shutdown).

## Messages to Claude Code go through the first time

- A message to a Claude Code chat sometimes showed as sent but got no reply
  until it was sent again, usually one with an image or after switching
  model. Harness restarted Claude Code to apply the change and the new
  process started before the old one had exited. It now waits for the old
  one first.

## Questions don't take over the chat

- A long agent question could cover the whole chat on Mac and Windows, and on
  iPhone and Android push Submit off the screen. The question now takes at most
  about half the pane, scrolls inside it, and keeps the answer field and buttons
  in view.

## Signing a server in to ChatGPT

- Signing graff on another computer (a Linux server, for example) in to
  ChatGPT from this app could fail with "The execution device is no longer
  waiting for this sign-in" while graff was still finishing. Harness now waits
  for graff's own result and reports it.

## Signed out? Harness says so

- If Harness has to sign you out because your saved sign-in was rejected,
  the sidebar now says "You've been signed out. Sign back in to sync your
  sessions." Your account's chats aren't gone; signing back in brings them
  back. Click the notice to sign in. It doesn't appear after you sign out on
  purpose, or while you're just offline.

## Starting folders name their device

- Settings → New project starting folder now shows which device each custom
  folder belongs to ("Custom on Server · /srv/work"). A folder saved for
  another computer no longer looks lost after a restart.

## Also

- Sidebar: selecting a chat keeps your open chat tabs, pane tabs stay compact
  when they wrap, and a single live chat tab keeps its header.
- Tool groups no longer show a dropdown that only repeats its header.
- The queue's keyboard shortcut works again after the composer loses focus.
- The `wait_for_turn` agent tool returns the current turn's replies, not older
  ones from the chat.
