# Harness v0.2.115

Stable desktop patch release for macOS, Windows and Linux.

## MCP servers you can see and fix

- Settings → **MCP servers** lists every server graff is configured with for
  the chat's folder, with its state: connected, starts on first use, failed
  (with the server's own error), sign-in required, off, or optional.
- Each row has **Reconnect**, **Sign in** when the server needs it, and an
  on/off switch. Expand a row to see its tools. **Check all** connects every
  server once and shows what's live.
- In the terminal client, `/mcp` lists the same states, and
  `/mcp reconnect <name>` and `/mcp enable|disable <name>` act on one server.
- This needs graff v0.302.30. With an older graff the page asks you to update
  it.

## Sign in with an Anthropic Console account

- Settings → Accounts → **Anthropic Console** signs graff in to your Anthropic
  Console account, so chats on Claude models bill to that account's API
  credits. The sign-in page opens in your browser; paste the code it shows
  back into the dialog. The account then shows as signed in.
- It uses Anthropic's `ant` command-line tool, which must be installed on the
  computer that runs graff. Codegraff cloud machines now include it.

## No more constant redraws

- A split pane whose chat ended on a message with no reply (for example a
  `/compact` that never answered) kept showing a working spinner forever,
  and that spinner redrew the whole window many times a second. Panes now
  follow the chat's real state, so the spinner stops and the window stays
  still.

## The terminal client stays current

- `graff tui` now always runs the terminal client that matches your Harness.
  Harness installs it on launch, checks it against the release's checksum,
  points `graff-tui` at it and removes older versions. Before, nothing
  updated it, so a computer kept its first copy and missed later fixes, such
  as steering a running turn by sending a message.

## Narrow panes

- In a many-way split, the composer's footer no longer overlaps itself: the
  branch and checkout controls clip, "Using ChatGPT plan" shortens, and the
  context ring stays whole.
