# Harness v0.2.117

Stable desktop patch release for macOS, Windows and Linux.

## Dictation hears you on macOS

- The composer's microphone started a dictation session but never typed
  anything on macOS: Harness never asked for microphone access, so it heard
  only silence. Harness now asks for the microphone the first time you
  dictate. Allow it, and your words appear in the draft as you talk.
- If you denied access before, turn Harness on in System Settings → Privacy
  & Security → Microphone.
