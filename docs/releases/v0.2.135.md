# Harness v0.2.135

Desktop release for macOS, Windows and Linux: updates move to an icon in the
titlebar, and once a new version is downloaded Harness restarts into it on its
own while nothing would be interrupted. Runs that a quit, crash or update
cuts short pick themselves back up, graff included, without asking an
agent's question twice.

## Updates

- The update notice is now an icon in the titlebar, next to **+**, instead of
  a strip above the account menu. It shows when a new version is downloading,
  ready, or failed; hover for details. Click it to restart into a ready
  update now, or to try a failed download again.
- When an update is ready, Harness closes and reopens on the new version by
  itself, but only when it's safe: no agent on this computer is working or
  waiting on an answer, no file has unsaved edits, no composer has an unsent
  message or attachment, no terminal is open, and you haven't used the app
  for a minute (10 seconds if another app is in front).
- A 10-second notice comes first, with **Restart now** and **Later**. Any
  input during the countdown cancels it until the next quiet moment. **Later**
  skips the automatic restart for that version; it still installs when you
  quit.
- If Harness isn't the app in front, it reopens in the background without
  taking focus. It comes back with the same windows, chat tabs, splits and
  selected chat, and shows **Updated to v0.2.135** once.
- Settings → Devices has **Restart automatically to install updates** (on by
  default). The version card there follows the same download: it shows
  progress, **Restart to update** once ready, and **Try again** after a
  failure. `HARNESS_AUTO_UPDATE=0` still turns automatic updates off.

## Runs pick back up after a restart

- Quitting Harness (⌘Q, **Restart now**, installing an update on quit) now
  lets the engine settle its runs before the app exits. Before, a quit with
  an agent working cut it off mid-stream, and the next launch treated it as a
  crash.
- A turn cut short by a quit, crash or update resumes on its own on the same
  agent and conversation, graff (Codegraff) included, even when the chat's
  settings hadn't been saved yet. A quit that was itself cut short no longer
  sends the turn twice.
- A run that was waiting on your answer to an agent's question is no longer
  asked the same question again. The original question stays answerable, and
  answering it carries on the run.
- The note in the chat is calmer: "Harness restarted — picking this run back
  up" (or "Harness updated to v0.2.135 — …"), as a grey chip instead of a red
  error. A run that won't resume still says so.

Mobile builds are distributed separately; this desktop release does not itself
update TestFlight, App Store or Play installations.
