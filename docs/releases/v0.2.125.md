# Harness v0.2.125

Desktop release for macOS, Windows and Linux, combining the design-preview and
engine reliability stack with peer-message spam protection.

## Design previews

- Open workspace file references and self-contained HTML previews from the
  originating chat, including chats hosted on another device.
- On macOS and Linux, HTML previews run in separate ephemeral native contexts
  with restricted navigation/networking, isolated scripts, scoped controls and
  bounded preview-local state. Reloading or closing discards that state.
- Missing isolation controls fail closed. Windows retains source links but does
  not execute HTML previews in an external browser.
- Includes compatible carousel and Tweak-style controls, not a full Apps SDK or
  proprietary plugin host. MIT notices for the adapted Zeron code are retained.

## Streaming and checkout reliability

- Avoid rewriting complete document snapshots for every streaming sync
  acknowledgement while retaining prompt persistence after local edits,
  disconnects and durable-outbox failures.
- Refresh source context when an agent enters its worktree. Ask before a new
  turn continues on a branch changed underneath its conversation.
- Preserve held attachments and request settings across engine restart. If the
  branch changes again while confirmation is open, require new consent rather
  than silently accepting the later branch.
- Keep outstanding branch questions discoverable even after many held sends.
- Allocate the capped Git capture buffer on the heap instead of overflowing a
  default worker stack.

## Agent coordination

- Stop requesting a reply to every peer update. Direct messages are for
  actionable questions, blockers and final requested results; progress belongs
  in non-waking room posts.
- Refuse another direct message while that sender already has one queued for
  the recipient, preserving earlier work and pending human approvals.
- Bound automatic peer reply chains to four deliveries. A new human request
  starts a new chain. The queue check is a preflight, not an atomic reservation.

## iOS source changes

- Add local memory, CPU, logical payload-write and callback-cadence summaries.
  These are not physical disk-write counters or rendered GPU FPS; existing
  consent-controlled diagnostics remain separate.
- Preserve the transcript history window while reading during live streaming,
  with recovery and actual realized-cell position regression coverage.

Mobile builds are distributed separately; this desktop release does not itself
update TestFlight or App Store installations.
