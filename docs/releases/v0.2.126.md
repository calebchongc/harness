# Harness v0.2.126

Desktop sidebar fix for macOS, Windows and Linux.

- Keep the project picker and session list visible when many chat tabs are open.
  The tab list takes at most 40% of the sidebar height; its rows scroll instead
  of pushing projects off the bottom of the window.
- Keep the tab count header fixed, preserve readable row heights, and reveal
  the active tab when switching tabs or restoring the workspace.

Includes the design previews, streaming persistence improvements, checkout
confirmation and peer-message spam guards from v0.2.125. Mobile distributions
are separate; this desktop release does not update TestFlight or the App Store.
